# Random Walk Animation

A small animation of a 2D random walk, built with HTML, CSS and JavaScript
(HTML Canvas).

## What it does

- Starts at the centre of the canvas.
- Picks a random direction and draws a line of fixed length (70 px) in that direction.
- Repeats this for 5 steps, so you see a random path being drawn.
- Each direction is chosen so the path never leaves the canvas.

## How to run it

1. Download or clone this repository.
2. Keep all three files in the same folder.
3. Open `randwalk.html` in any web browser.

Refresh the page to see a new random path.

## Files

- `randwalk.html` - the page with the canvas
- `randomwalk.css` - styling
- `randwalk.js` - the animation code

## Built with

HTML, CSS, JavaScript (Canvas API, `requestAnimationFrame`, Promises)
